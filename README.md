# Jade Umber static website

Extract all files into the root of your GitHub repository.

GitHub repository Settings > Pages > Build and deployment: Deploy from a branch, main, /(root), Save.

This build expects base path `/jadeumber/`.

For custom domain jadeumber.com use the separate root-domain build, not the project-path build.

IMPORTANT: Checkout is disabled in commerce-config.js. Inquiry forms may generate downloadable text only; they do not send submissions. Review policies, copy, pricing and contact information before launch.
